# Evidence Interfaces & Dataclasses (AI Context)

**Target Audience**: AI coding assistants implementing new `EvidenceSource` plugins or modifying pipeline data transfer.

## File Location
`aletheia/evidence.py`

## Protocol: `EvidenceSource`
Any new evidence connector (e.g., adding Wikipedia or a proprietary API) must implement this protocol.
```python
class EvidenceSource(Protocol):
    source_id: str

    async def collect(
        self,
        claim: PolicyClaim,
        *,
        plan: RoutingPlan | None = None,
    ) -> SourceOutput:
        ...
```

## Dataclass: `RoutingPlan`
Generated by `ClaimRouter.route()`. Determines the parallel execution strategy.
```python
@dataclass(frozen=True)
class RoutingPlan:
    claim_type: ClaimType
    source_ids: list[str]                      # Primary sources executed concurrently
    fallback_source_id: str | None             # Triggered if primary yields nothing
    deep_research_source_ids: list[str]        # Triggered if confidence is low
```

## Dataclass: `SourceOutput`
The normalized return type from *every* `EvidenceSource.collect()` call.
```python
@dataclass
class SourceOutput:
    source_id: str
    breaks: list[MethodologyChange]            # Documented methodology breaks
    analysis: dict[str, Any] | None            # Arbitrary JSON metric data (e.g., API math)
    evidence_docs: list[dict[str, Any]]        # Unstructured text snippets
    errors: list[str]                          # Execution exceptions (prevents hard crashes)
```

## Dataclass: `AggregatedEvidence`
The final merged result created by `EvidenceAggregator.aggregate()`, passed to the `EditorAgent`.
```python
@dataclass
class AggregatedEvidence:
    plan: RoutingPlan
    source_outputs: list[SourceOutput]
    breaks: list[MethodologyChange]            # Deduplicated across all sources
    analysis: dict[str, Any]                   # Merged analysis blocks
    evidence_docs: list[dict[str, Any]]        # Ranked descending by relevance/confidence
    aggregate_confidence: float                # 0.0 - 1.0 Pipeline confidence score
    fallback_used: bool                        # True if fallback_source_id was invoked
```
